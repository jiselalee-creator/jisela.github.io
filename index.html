SQL & Database Architecture Extern · October 2026–present

The question

How can disconnected e-commerce sources become a useful foundation for business decisions?

My work

Built a SQLite analytics database unifying six e-commerce sources. Created cleaned views to remove bot traffic, and developed marketing-channel attribution across more than 400 referral sources to connect ad spend with revenue.

What this brings together

Database structure, data validation, SQL transformations, and the business context behind a metric. The goal is a clearer path from raw data to useful analysis.

02 / COURSE PROJECT · R

One dataset. More than one story.

CSC113 · Data Science for the World · Fall 2026

Rggplot2dplyrData visualization

The question

What changes when we compare the number of named storms with the share that reached hurricane strength?

My work

Used the storms dataset in R to examine wind speed and pressure distributions, map 2012 storm positions, and count unique named storms and hurricanes by year. Combined summaries with bind_rows and used ggplot2 for lines, points, and histograms.

The lesson

Repeated observations are not separate storms. Counting distinct year–name pairs avoids overcounting. Counts and proportions also answer different questions, so a title must match the evidence in the plot.

About the preview

The chart on this page uses the 1975–1984 excerpt printed in my completed Lab 6 notebook. It is a small excerpt, not a summary of the full record or a claim about the cause of changes in storm activity.
